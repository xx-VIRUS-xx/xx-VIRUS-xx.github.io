dedupe_tradeoff.py is a stdlib-only model of the threshold trade-off in Part 2 of "Designing an election".
All inputs (roll size, duplicate rate, score noise) are synthetic and editable at the top of the file; nothing is real data.
Run with /usr/bin/python3 dedupe_tradeoff.py; it prints markdown tables for 2 duplicate rates x 2 noise levels.
